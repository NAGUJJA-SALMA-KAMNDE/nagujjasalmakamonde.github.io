Capstone project

Final-year project · Makerere CEDAT

FLISR for the Kiwatule–Kisaasi 11 kV Feeders

Fault Location, Isolation and Service Restoration · Ntinda 33/11 kV Substation · Group project

A study of how automated fault location, isolation and service restoration could improve reliability on feeders supplied from Ntinda substation, set in the context of Uganda's power sector (UEDCL, ERA, MEMD).

  • Network modelling and simulation in DIgSILENT PowerFactory
  • Overload analysis, including a conductor upgrade comparison (AACSR 100 mm² against ACSR Rabbit 50 mm²)
  • Reliability index analysis (SAIDI, SAIFI, CAIDI) for the Bukoto, Kisaasi, Kiwatule and Kyambogo feeders
  • Relay coordination in MATLAB/Simulink
  • Cost-benefit analysis in UGX: energy-not-supplied recovery, NPV and payback period
  • Report and presentation produced in Word and LaTeX Beamer
