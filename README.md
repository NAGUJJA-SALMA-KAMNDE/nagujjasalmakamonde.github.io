# Salma Kamonde Nagujja | Portfolio

Portfolio of a final-year electrical engineering student at Makerere University, Kampala.

Static site: one `index.html`, no build step, no dependencies.

## Publish on GitHub Pages

1. Create a repository named `<your-username>.github.io` (or any name).
2. Upload `index.html`, `README.md` and `.nojekyll`.
3. Go to **Settings → Pages**, choose **Deploy from a branch**, `main`, `/ (root)`, then save.
4. The site goes live at `https://<your-username>.github.io/`.

## Edit

All content is in `index.html`; search for the section ids (`#capstone`, `#experience`, `#training`).
